## About

I am an AI Engineer and Computer Science student at Nile University focused on building Generative AI systems that can move from an idea or research concept into working software.

My work sits across LLM applications, retrieval-augmented generation, model fine-tuning, backend APIs, databases, and modern frontend development. I enjoy taking an AI capability and turning it into something structured, testable, and useful rather than stopping at a model or prototype.

I care about building systems that are not only intelligent, but also grounded, testable, scalable, and useful for real users. I am particularly interested in LLM engineering, RAG pipelines, AI validation, FastAPI services, PostgreSQL, and full-stack AI products.

<summary><b>AI Health & Fitness Coaching Platform</b></summary>

<br>

**Status: Active Development · Not Yet Deployed**

A full-stack AI health platform built as a B.Sc. Senior Capstone at Nile University. The system converts two smartphone photos into body-composition insights and generates personalized, safety-checked workout and nutrition plans.

<br>

| Category | Details |
|---|---|
| Stack | Python, PyTorch, Hugging Face PEFT, FastAPI, PostgreSQL, React |
| Scale | 2.5M-record USDA food database |
| Performance | RAG-grounded meal generation with deterministic calorie and macro validation |
| Security | Backend API architecture, validation layer, structured outputs |
| Impact | Reduces hallucination risk and improves trust in AI-generated health recommendations |
| Repository | [View Repository](https://github.com/Kareemtantawii/AI-Coach) |

<br>

Built an AI platform integrating fine-tuned LLMs, backend APIs, database retrieval, and frontend delivery. Designed the NutriPlan engine using calorie and macro logic with LoRA-fine-tuned generation. Implemented RAG over verified foods to ground nutrition plans in real database records. Added a validator that recalculates calories and macros to enforce targets and reduce hallucination risk.
